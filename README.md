# Site Measure

Веб-приложение (PWA) для замеров голых фасадных стен на объекте: размеры в дюймах с дробями, схема стены в масштабе, фото с размерами и контурами поверх, экспорт DXF для Autodesk Fusion (Insert → Insert DXF, 1:1, дюймы).

**Приложение:** https://yakushenkoandrey.github.io/site-measure/

Данные хранятся только на телефоне (IndexedDB). В репозиторий и на сервер ничего не уходит. Полное ТЗ — [SPEC.md](SPEC.md).

## Как поставить на iPhone

1. Откройте ссылку выше в **Safari** (не в Chrome).
2. Нажмите «Поделиться» (квадрат со стрелкой) → **«На экран Домой»** → «Добавить».
3. Запускайте с иконки Measure: приложение откроется на весь экран и будет работать без интернета.
4. Регулярно делайте **«Резервную копию»** объекта: iOS может удалить данные веб-приложения, если им долго не пользоваться.

Обновление: после изменения файлов приложение подтягивает новую версию при следующем запуске с интернетом (иногда нужно закрыть и открыть его дважды).

## Импорт DXF во Fusion

Insert → Insert DXF → выбрать файл → единицы **inch**. Левый нижний угол стены — в точке (0, 0). Слои: `WALL` (контур), `OPENINGS` (проёмы), `TEXT` (подписи). Формат — AutoCAD R12 (AC1009): самый совместимый, но в нём нет переменной `$INSUNITS`, поэтому дюймы выбираются в окне вставки.

## Разработка

Чистый HTML/CSS/JS, без сборки. Локально:

```
python -m http.server 8000
```

и открыть http://localhost:8000/.

Тесты (Node 20+, без зависимостей):

```
node --test tests/
```

Тест чтения DXF через `ezdxf` запускается, если найден Python с `ezdxf` (`python3`/`python` или путь в переменной `EZDXF_PYTHON`), иначе пропускается.

При любом изменении файлов приложения увеличьте `VERSION` в `sw.js`, иначе телефон продолжит показывать старую версию из кэша.

Иконки: `python tools/make_icons.py` (нужен Pillow).

## Структура

| Файл | Что делает |
|---|---|
| `index.html`, `styles.css`, `app.js` | Интерфейс, экраны, клавиатура для размеров |
| `units.js` | Разбор и форматирование дюймов с дробями |
| `validate.js` | Проверки проёмов |
| `dxf.js` | Генерация DXF |
| `sketch.js` | Схема стены (SVG) |
| `storage.js` | IndexedDB, резервные копии |
| `marks.js` | Пометки на фото: геометрия и отрисовка |
| `photo-editor.js` | Редактор фото: размеры, контуры, линии, зум |
| `sw.js` | Офлайн-кэш |
