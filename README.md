# Site Measure

Сайт-приложение для замеров на объекте: фото → рёбра → размеры в дюймах → отчёт PDF.

**Открыть:** https://yakushenkoandrey.github.io/site-measure/

- Работает в Safari на iPhone и iPad, ставится на экран «Домой» и открывается без интернета.
- На iPad в альбомной ориентации фото слева, клавиатура и лупа справа; размеры можно набирать на внешней клавиатуре (Enter — следующее ребро, Esc — готово).
- Без аккаунтов, без сервера и без ИИ: объекты, фото и размеры хранятся только на этом телефоне.
- Фото хранятся в полном разрешении (до 4032 px), лупа показывает их без размытия.

## Как поставить на iPhone

1. Откройте ссылку выше в **Safari**.
2. «Поделиться» (квадрат со стрелкой) → **«На экран Домой»** → «Добавить».
3. Запускайте с иконки Measure.

## Как пользоваться

1. **＋ Новый объект** — название и адрес.
2. **📷 Снять** или **🖼 Из галереи** (можно несколько фото сразу). После одного нового фото сразу открывается разметка.
3. **＋ Ребро** — проведите пальцем вдоль ребра. Над пальцем появляется лупа с прицелом.
   Двумя пальцами — увеличить фото. Нажмите на ребро, чтобы выбрать его; белые точки на концах можно двигать
   (точка сдвигается на столько же, на сколько палец, и не прячется под ним).
4. Впишите размер своей клавиатурой (дюймы, дроби до 1/16, футы `'`), при желании примечание «от чего до чего».
   **Далее ›** — к следующему ребру без размера.
5. **⇪ Экспорт**: PDF (каждое фото на странице с пронумерованными размерами и примечаниями), CSV или ZIP.
   Файл открывается в меню «Поделиться»: в Файлы, на почту, в мессенджер.

## Резервная копия

iOS может удалить данные сайта, если им долго не пользоваться. На экране объекта «⋯» → **Резервная копия** —
ZIP со всеми фото и размерами; сохраните его в Файлы или iCloud. Восстановление — ссылка внизу главного экрана.

## Разработка

Чистый HTML/CSS/JS без сборки.

```
node tools/dev-server.mjs      # http://127.0.0.1:8766/
node --test tests/             # тесты, Node 20+
```

При любом изменении файлов приложения увеличьте `VERSION` в `sw.js`, иначе телефон продолжит показывать старую версию из кэша.

| Файл | Что делает |
|---|---|
| `index.html` | Страница и стили |
| `app.js` | Экраны, редактор фото, лупа, клавиатура, экспорт, резервные копии |
| `store.js` | Хранение на телефоне (IndexedDB) |
| `export.js` | CSV, PDF, ZIP |
| `units.js` | Дюймы с дробями: разбор и форматирование |
| `sw.js` | Офлайн-кэш |

`SPEC.md` — первоначальное ТЗ (первая версия со стенами и проёмами); текущая версия устроена иначе, см. выше.
